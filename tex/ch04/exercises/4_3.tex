For QDA, the Bayes classifier assigns an observation $X = x$ to the class for
which
\[
  \delta_k(x) = -\frac{1}{2}x^T \mathbf{\Sigma}_k^{-1}x
  + x^T \mathbf{\Sigma}_k^{-1}\mu_k
  - \frac{1}{2} \mu_k^T \mathbf{\Sigma}_k^{-1}\mu_k
  - \frac{1}{2}\log{\lvert \Sigma_k \rvert} + \log{\pi_k}
\]
is largest. However, if we supose that $p = 1$, we have $K$ classes, and
$X \sim N(\mu_k, \sigma_k^2)$, then we have the normal density function given
by
\[
  f_k(x) = \frac{1}{\sqrt{2\pi}\sigma_k}
  \exp{\biggl(-\frac{1}{2\sigma_k^2}{(x - \mu_k)}^2\biggr)},
\]
so that plugging the above into (4.15) yields
\[
  p_k(x) = \frac{\pi_k \frac{1}{\sqrt{2\pi}\sigma_k^2}
    \exp{\left(-\frac{1}{2\sigma_k^2}{(x - \mu_k)}^2\right)}}
    {\sum_{l=1}^K{\pi_l \frac{1}{\sqrt{2\pi}\sigma_l^2}
  \exp{\left(-\frac{1}{2\sigma_l^2}{(x - \mu_l)}^2\right)}}}.
\]
Taking the log of the above yields
\begin{equation*}
  \begin{split}
    & \log{\bigl(p_k(x)\bigr)} \\
    &= \log{\left(\frac{\pi_k \frac{1}{\sqrt{2\pi}\sigma_k^2}
          \exp{\left(-\frac{1}{2\sigma_k^2}{(x - \mu_k)}^2\right)}}
          {\sum_{l=1}^K{\pi_l \frac{1}{\sqrt{2\pi}\sigma_l^2}
    \exp{\left(-\frac{1}{2\sigma_l^2}{(x - \mu_l)}^2\right)}}}\right)} \\
    &= \log{\left(\pi_k \frac{1}{\sqrt{2\pi}\sigma_k^2}
    \exp{\left(-\frac{1}{2\sigma_k^2}{(x - \mu_k)}^2\right)}\right)} \\
    &\quad - \log{\left(\sum_{l=1}^K{\pi_l \frac{1}{\sqrt{2\pi}\sigma_l^2}
    \exp{\left(-\frac{1}{2\sigma_l^2}{(x - \mu_l)}^2\right)}}\right)}.
  \end{split}
\end{equation*}
Again, the second term does not depend upon $k$, so that we have
\begin{equation*}
  \begin{split}
    & \log{\left(\pi_k \frac{1}{\sqrt{2\pi}\sigma_k^2}
    \exp{\left(-\frac{1}{2\sigma_k^2}{(x - \mu_k)}^2\right)}\right)} \\
    &= \log{(\pi_k)} + \log{\left(\frac{1}{\sqrt{2\pi}\sigma_k^2}
    \exp{\left(-\frac{1}{2\sigma_k^2}{(x - \mu_k)}^2\right)}\right)} \\
    &= \log{(\pi_k)} + \log{\left(\frac{1}{\sqrt{2\pi}\sigma_k^2}\right)}
    - \frac{1}{2\sigma_k^2}{(x - \mu_k)}^2.
  \end{split}
\end{equation*}
Here, all terms do depend upon $k$, so we then have the expansion of the
right-hand side given by
\[
  \delta_k(x) = x \cdot \frac{\mu_k}{\sigma_k^2} - \frac{\mu_k^2}{2\sigma_k^2}
  - \frac{1}{2\sigma_k^2}x^2 + \log{(\pi_k)}
  + \log{\left(\frac{1}{\sqrt{2\pi}\sigma_k^2}\right)}.
\]
Since all terms depend upon $k$, the Bayes classifier assigns an observation to
the class for which the function $\delta_k(x)$ which is quadratic due to the
presence of the $x^2$ term in the above.
